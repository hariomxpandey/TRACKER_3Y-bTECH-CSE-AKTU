### 🎯 High-Yield Scoring Topics (Semester V)

#### 1. Database Management System (BCS501)
- **Unit 1:** 3-Schema architecture, physical vs logical data independence, ER to Relational schema reduction rules (1:1, 1:N, M:N).
- **Unit 2:** Relational Algebra queries (Natural join, division, projection) and SQL subqueries / joins.
- **Unit 3:** Finding candidate keys using FD closure, Normal forms testing (2NF, 3NF, BCNF decomposition) and Lossless Join test.
- **Unit 4:** Conflict serializability testing using Precedence Graph (topological sort), Log-based recovery (undo/redo rules).
- **Unit 5:** Two-Phase Locking (Strict vs Rigorous 2PL), Timestamp ordering protocol & Thomas' write rule.

#### 2. Web Technology (BCS502)
- **Unit 1 & 2:** XML DTD vs XML Schema, DOM vs SAX parser differences, CSS Box Model & Flexbox layout.
- **Unit 3:** JavaScript DOM event handling, form validation scripts, Java Socket programming (`ServerSocket` and `Socket`).
- **Unit 4:** Node.js event-driven non-blocking architecture, Express route handling, MongoDB CRUD operations.
- **Unit 5:** Servlet lifecycle (`init`, `service`, `destroy`), Session tracking (Cookies vs `HttpSession`), JSP implicit objects & Scripting tags.

#### 3. Design and Analysis of Algorithm (BCS503)
- **Unit 1:** Master Theorem cases, Quick Sort average vs worst case analysis, Heap Sort derivation, Counting Sort.
- **Unit 2:** Red-Black Tree insertion rotations, B-Tree insertion & deletion, Fibonacci Heap amortized bounds.
- **Unit 3:** Strassen's Matrix Multiplication recurrence, Dijkstra's algorithm, Kruskal's MST using Union-Find.
- **Unit 4:** 0/1 Knapsack dynamic programming table, Floyd-Warshall all-pairs shortest paths, N-Queens backtracking.
- **Unit 5:** KMP algorithm prefix table computation, P vs NP vs NP-Complete definitions, Vertex Cover approximation.

### 🎯 High-Yield Scoring Topics (Semester VI)

#### 1. Software Engineering (BCS601)
- **Unit 1:** Waterfall vs Spiral vs Agile models, Software crisis definition.
- **Unit 2:** IEEE 830 standard SRS document characteristics, DFD Level 0, 1, 2, SEI-CMM 5 levels.
- **Unit 3:** Cohesion types (functional, sequential, coincidental), Coupling types, McCabe's Cyclomatic Complexity $V(G) = E - N + 2P$.
- **Unit 4:** Black-box (Equivalence Partitioning, Boundary Value Analysis) vs White-box testing (Basis Path, Condition testing).
- **Unit 5:** COCOMO basic, intermediate, and detailed formulas, SCM change control flow, Software maintenance categories.

#### 2. Compiler Design (BCS602)
- **Unit 1:** 6 Phases of compiler and data structures passed, DFA construction from regular expression, LEX structure.
- **Unit 2:** FIRST and FOLLOW computation algorithm, LL(1) parsing table construction and conflict checking, SLR(1) / CLR(1) / LALR(1) item sets and parsing table construction.
- **Unit 3:** S-Attributed vs L-Attributed SDD, Three-Address Code generation (Quadruples, Triples, Indirect Triples).
- **Unit 4:** Activation Record layout, Parameter passing methods, Lexical vs Syntactic error handling.
- **Unit 5:** Basic block identification rules, Flow graph construction, DAG representation for basic block optimization, Loop unrolling & common subexpression elimination.

#### 3. Computer Networks (BCS603)
- **Unit 1:** OSI 7 layers vs TCP/IP 4 layers with protocols, Guided transmission media, Circuit vs Packet switching.
- **Unit 2:** CRC polynomial error check calculation, Stop-and-Wait vs Go-Back-N vs Selective Repeat sliding window efficiency, CSMA/CD backoff algorithm.
- **Unit 3:** IPv4 addressing, Subnetting calculations (CIDR notation, network address, broadcast address), Distance Vector routing & Count-to-Infinity, Dijkstra's link state.
- **Unit 4:** TCP 3-way handshake & 4-way termination, TCP sliding window flow control, TCP congestion control phases (Slow Start, Congestion Avoidance, Fast Retransmit).
- **Unit 5:** DNS hierarchy and iterative/recursive queries, HTTP persistent vs non-persistent connections, Symmetric vs Asymmetric key cryptography (RSA basics).

2. **Mastery Checkboxes:** Mark topics as you study them in class, library, or YouTube. The progress meters will update in real time.
